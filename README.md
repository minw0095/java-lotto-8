# java-lotto-precourse



### 입력 

1. 구입 금액 입력 받기

   개당 1000원인 로또의 구입 금액을 받는다.

   * 숫자가 아닐 시 예외 처리

   * 1,000원 미만 혹은 1,000원 단위가 아닐 시 예외 처리

     

2. 당첨 번호 입력 받기

   콤마(,)로 구분 된 6자리 숫자를 받는다.

   * 6자리가 아닐 시 예외 처리

   * 중복된 숫자가 있을 시 예외 처리

   * 숫자가 아닐 시 예외 처리

   * 1 ~45의 숫자가 아닐 시 예외 처리

     

3. 보너스 번호 입력 받기

   당첨 번호와 겹치지 않는 숫자를 받는다.

   - 숫자가 아닐 시 예외 처리
   - 당첨 번호와 중복 될 시 예외 처리
   - 1 ~45의 숫자가 아닐 시 예외 처리



### 기능

1. 로또 구매

   - 입력 받은 비용 / 1000의 갯수 만큼 로또를 구입
   - 구매된 로또의 번호를 갯수 만큼 출력

2. 당첨 확인

   - 입력된 당첨 번호와 구매된 로또를 각각 비교
   - 당첨은 1등부터 5등까지 있다. 당첨 기준과 금액은 아래 기준으로 저장.
     - 1등: 6개 번호 일치 / 2,000,000,000원
     - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
     - 3등: 5개 번호 일치 / 1,500,000원
     - 4등: 4개 번호 일치 / 50,000원
     - 5등: 3개 번호 일치 / 5,000원
   - 당첨 확인이 끝나면 수익률을 계산.(소수점 둘째 자리에서 반올림)

   ```
   수익률 = (당첨된 총상금 / 구입 금액) * 100
   ```
